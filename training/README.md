# Training: fine-tune a document model on synthetic German data

This trains an **OCR-free** Donut model (image → structured JSON) on the
synthetic dataset, to compare against the OCR baselines (Surya 90% / Apple
Vision 85%) on the **real** held-out `test_documents/`.

Training runs on a **free cloud GPU** (Kaggle T4) — not your Mac and not the
RX 6600 (AMD/ROCm is unreliable for training). Your machine only generates the
data and runs inference.

## 1. Generate the data (local, your Mac)

```bash
python scripts/generate_synthetic_docs.py --n 3000     # 12,000 docs → data/synthetic
```

## 2. Package it for upload (local)

```bash
python scripts/package_dataset.py                      # -> data/german-docs-synthetic.zip
```

## 3. Upload to Kaggle as a Dataset

- https://www.kaggle.com/datasets → **New Dataset** → upload `german-docs-synthetic.zip`
  (Kaggle auto-extracts the contents).
- The notebook **auto-detects** the dataset path (it globs for
  `manifest.train.jsonl` under `/kaggle/input/`), so the exact slug/mount
  doesn't matter — just attach it as an Input.

## 4. Train

- New Notebook → **File → Import Notebook** → upload `training/train_donut.ipynb`.
- **Add Input** → attach your dataset. **Settings → Accelerator → GPU T4.**
- **Run All.** Checkpoints save to `/kaggle/working/donut-german`.
- Defaults train on a 6,000-doc subset (`MAX_TRAIN`) to fit a session
  (~3–5 h); raise it once the pipeline is proven.

## 5. Evaluate on the REAL hold-out (local)

- Download `/kaggle/working/donut-german` (Output tab).
- Wrap it behind the project's extractor interface (same pattern as
  `apple_vision_extractor.py`) and run:

```bash
python scripts/eval_german_documents.py
```

That gives the head-to-head accuracy on the real, degraded documents — the
result to show: *"a model trained only on synthetic data, beating general
OCR on real German scans."*

## Notes
- `train_donut.ipynb` is generated by `build_notebook.py` (keeps the JSON valid
  and regenerable): `python training/build_notebook.py`.
- If a field underperforms, add targeted layout/degradation variety to
  `backend/app/synth/` and regenerate — the eval drives the data, not guesswork.
